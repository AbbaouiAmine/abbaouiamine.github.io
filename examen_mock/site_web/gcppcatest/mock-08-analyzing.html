Question 5 / 60 D4 M3 S1 multi D4/M3/S1 · Principles of Site Reliability Engineering (SRE)
Your team wants to implement Site Reliability Engineering (SRE) practices. You need to define error budgets for your service. Which TWO factors determine how error budget is calculated?
  • The measurement window (e.g., 30 days).
  • The cloud provider's uptime SLA.
  • The SLO target (e.g., 99.9% availability).
  • The programming language used.
  • The number of developers on the team.
Bonne réponse : A, C
Error budget = (100% - SLO) × measurement window. For example, a 99.9% SLO over 30 days allows 0.1% × 30 days = 43.2 minutes of downtime. Team size (C), provider SLA (D), and programming language (E) don't factor into error budget calculation.

  • Run the query during off-peak hours.
  • Increase the query's maximum bytes billed limit.

Bonne réponse : A

Off-peak hours (C) don't address the root cause. Location (D) doesn't affect this issue.
