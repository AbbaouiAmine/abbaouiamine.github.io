Question 1 / 60 D1 M1 S4 single D1/M1/S4 · Integration with External Systems and Moving Data
You are designing the network architecture for a global enterprise. You have applications in the US, Europe, and Asia. You want instances in all regions to communicate via internal private IPs without using external IP addresses or VPN tunnels between regions. What should you configure?
  • A single Global IP address.
  • Cloud Interconnect.
  • A Global VPC (one VPC spanning all regions).
  • VPC Peering between three separate Regional VPCs.
Bonne réponse : C
Google Cloud VPCs are global resources. A single VPC can contain subnets in multiple regions (e.g., us-central1, europe-west1, asia-northeast1). Instances in these subnets can communicate via their internal IP addresses over Google's global private network by default, with no need for VPNs or Peering.
