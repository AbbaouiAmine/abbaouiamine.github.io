Question 1 / 60single
A startup is building a mobile app that will serve users globally. They expect rapid growth from 1,000 to 1 million users within 6 months. The app requires a NoSQL database with strong consistency, automatic scaling, and global distribution. Which database should you recommend?
  • Cloud Spanner.
  • Cloud Firestore in Native mode.
  • Bigtable with replication.
  • Cloud SQL with read replicas in multiple regions.
Bonne réponse : A
Cloud Spanner provides strong consistency, automatic horizontal scaling, and global distribution with multi-region configurations. It's designed for applications that need the scale of NoSQL with the consistency and structure of SQL. Firestore provides eventual consistency in multi-region, Cloud SQL requires manual scaling and read replicas don't provide strong consistency for writes, and Bigtable provides eventual consistency.
Référence https://cloud.google.com/spanner/docs/overview

  • Cloud Tasks for guaranteed task execution.

Bonne réponse : A, C
