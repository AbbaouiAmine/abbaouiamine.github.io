Question 1 / 60 D1 M1 S4 single D1/M1/S4 · Integration with External Systems and Moving Data
Mountkirk Games is launching a new mobile FPS game globally. They expect high throughput of small UDP packets for player movement updates. They need a global load balancing solution that supports UDP and creates a single anycast IP for clients worldwide. What should you choose?
  • Cloud DNS with round-robin records.
  • Global External Application Load Balancer.
  • Global External Proxy Network Load Balancer.
  • Regional External Network Load Balancer.
Bonne réponse : C
Player movement in FPS games typically uses UDP. The Global External Proxy Network Load Balancer (formerly SSL Proxy/TCP Proxy, now unified) supports UDP traffic with a global Anycast IP. This allows clients to connect to a single IP and get routed to the nearest healthy region (with termination at the edge). Option B is HTTP/TCP only. Option C is regional, not global anycast.

  • Cloud Run Jobs for the execution environment.
  • Pub/Sub to trigger App Engine Standard.

Bonne réponse : A, C

Triggering a Job from Eventarc (often via a small workflow or function proxy, or direct integration evolved) is the pattern. Cloud Functions (B) has timeouts (9-60 mins) and isn't ideal for heavy media processing compared to Jobs.
