=== Q1 | domain: LLM Fundamentals | pick: 1 | section: A ===
A regression test flakes because it compares the model's output to a fixed expected string. Best fix?
A) Assert on the structure or key facts of the output rather than an exact string, since generation is non-deterministic
B) Pin temperature to 0 and assume output is now byte-identical every run, keeping the exact-string assertion in place
C) Retry the test until it happens to pass
D) Move the test to the largest model tier
Correct: A
Why: Generation is non-deterministic, so grade on structure or key facts, not an exact string. Temperature 0 reduces variation but does not guarantee identical bytes, and retrying or upsizing does not make the assertion valid.

=== Q4 | domain: Cost & Tokens | pick: 1 | section: A ===
In a long agent session the same instruction prefix is re-sent every turn. What reduces the repeated input cost?
A) Cache checkpoints on the stable prefix
B) Lowering max_tokens each turn so responses are shorter, which brings the per-turn input cost down as the session goes on

=== Q5 | domain: Prompt Engineering | pick: 1 | section: B ===
